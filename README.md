# 8-bit CPU, RTL to GDS, with a 100% open-source flow (sky130A)

Educational material: an 8-bit CPU taken from synthesizable SystemVerilog through place-and-route to GDSII, using only public tools and the sky130A PDK.

This repository does not ship a foundry PDK or any proprietary files. The PDK is downloaded with `make pdk`. Checked-in results come from LibreLane 3.0.17 (Classic flow) and sky130A (ciel pin `8afc8346a57fe1ab7934ba5a6056ea8b43078e71`).

## What it is

The design is a small 8-bit CPU in SystemVerilog:

- **ALU** with add, subtract, multiply and divide (16-bit result), plus zero and error flags (including divide-by-zero).
- **Register bank** for operand, command, flag and output registers.
- **Memory** of eight 16-bit words, with load and store.
- **Control** FSM (`RST` → `FETCH` → `EXECUTE` → `STORE`) and a compact ISA on a 7-bit command word.
- **Input muxes** that can take operands from three data inputs or from the previous result.

The top-level module is `top`. `src/rtl/` is the original RTL. `src/rtl_synth/` is the synthesis copy: the only change is a default `out = '0;` in the ALU combinational block, which prevents an inferred latch and a Yosys combinational loop. `src/rtl/mux4_registered.sv` is included as a small unused helper; it is not instantiated by `top`.

## Open-source flow

| Step | Tools |
|---|---|
| RTL simulation | Icarus Verilog, Verilator |
| Synthesis | Yosys |
| Place and route | OpenROAD (via LibreLane) |
| Sign-off STA and power | OpenSTA, parasitics from OpenRCX |
| DRC | Magic, KLayout |
| LVS | Netgen |
| GDS stream-out / layout view | Magic, KLayout (`reports/final_5ns/top.png`) |
| Formal equivalence (optional, partial) | Yosys EQY |

## How to reproduce

Use a LibreLane environment (the flow was run with LibreLane 3.0.17):

```bash
cd ~/librelane && nix-shell
cd /path/to/cpu8-sky130-openflow

make pdk      # once: install sky130A at the pinned ciel version under ~/.ciel
make sim      # Icarus and Verilator, original RTL and synthesis copy
make synth    # standalone Yosys (area)
make flow     # RTL to GDS, default tag final_5ns / config.json (~3–6 min on 8 cores)
make flow TAG=final_8ns CONFIG=config_8ns.json
make gls      # gate-level simulation of the final netlist
make sta      # OpenSTA sign-off (SPEF + VCD from tb_light)
make eqy      # optional formal check; needs the PDK formal models from a flow run
```

If ciel returns a 500 from the default mirror, `make pdk` already uses the GitHub releases source. After a flow run, open the GDS with:

```bash
klayout runs/final_5ns/final/gds/top.gds
```

The `runs/` directory is not checked in; it is regenerated by `make flow`. Sign-off numbers and the layout image are in `reports/`.

### Standalone Yosys (area)

From `reports/yosys_standalone/stat_tt.rpt`: **10 188.5 µm²**, **1 004** cells. This run does not close timing. Yosys inside the LibreLane 5 ns flow (`DELAY 1`) reported **15 269.6 µm²** and **1 352** cells in the run's synthesis `stat.rpt` (not checked in; regenerated by `make flow`).

### Formal equivalence

`make eqy` is optional and was only partly successful: 51 partitions, 167 matched comparison points, **32 PASS**, **19 UNKNOWN**. Functional confidence rests on the 35/35 gate-level checks above.

## Notes

- Timing is limited by a long combinational path through the multiplier and divider. Pipelining MUL/DIV, or relaxing the clock period beyond 8 ns, would be the natural next step in this open flow.
- `constraints/top.sdc` uses `CLOCK_PERIOD` from the LibreLane config, so the same file serves both the 5 ns and 8 ns runs.
